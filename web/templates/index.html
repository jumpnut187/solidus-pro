Alloy Comparison

Use this to choose an alloy before selecting riser/chill strategy.

Shrinkage note: this app displays volumetric shrinkage. WCB shows ~8.3% and CF8 shows ~7.5% here, while handbook values like 2.0% or 2.5% are commonly linear shrinkage references and will not numerically match volumetric values.

Definition: Volumetric shrinkage is calculated from density change as volumetric = (1 - density_liquid / density_solid) * 100%. Equivalent linear shrinkage is only an approximation (for isotropic comparison only).

Units and Conversions

  • Volumetric shrinkage (this app): what the panel and results use.
  • Linear shrinkage (literature tables): often reported separately and not directly equal.
  • WCB example: density data gives about 8.3% volumetric; this is approximately 2.8% equivalent linear under isotropic approximation.
  • CF8 example: density data gives about 7.5% volumetric; this is approximately 2.6% equivalent linear under isotropic approximation.
  • Important: these equivalent linear values are only for orientation; your alloy-specific linear spec and density data can still differ.

Simulation Settings Guide

Control What it does How to use for good casting checks
Alloy Defines thermal/mechanical material constants used for solidification and risk scoring. Start with a material baseline closest to your foundry spec. WCB is common, C964 generally gives lower volumetric shrinkage than WCB, CA6NM is a balanced cast-steel option, and CF8 is usually harder to cast than WCB/C958.
Auto Mesh Uses ML recommendation for voxel size and mesh resolution. Enable for fast first pass, then validate with manual settings if hotspot regions move after refinement.
Voxel Size Controls geometric discretization. Smaller voxels capture narrow sections and high curvature defects better, but increase runtime and memory.
Refinement Level Controls additional resolution tuning on top of voxel size. Increase in complex geometry until key risk zones stop changing materially.
Part Type Marks geometry as cast, riser, riser post, or chill for feeding/chill physics. Only one way to properly model feeding behavior is to classify risers/chills correctly.
Shrinkage / Porosity Runs shrinkage-risk field plus combined porosity logic. Primary defect check. Lower high-risk region count/volume is better.
Hot Spot Flags voxels with delayed, isolated, late freeze behavior. Use to catch local solidification traps around ribs, ribs-thick junctions, and enclosed sections.
Niyama Criterion Highlights directional solidification risk, especially high thermal gradient/cooling imbalance areas. Higher Niyama severity means higher risk. Cross-check with shrinkage view in same region.
Hot Tear Risk Evaluates local tear risk from BTR-like behavior in late mushy-solid transition. Keep enabled for thin necks, transitions, and heavy section change locations.
Sand Burn-In Predicts where liquid metal tends to pull/scrape against refractory and expose defects. Use when gating and pouring speed can rub sand marks into critical surfaces.
Fraction Liquid Shows liquid fraction over time using simulation snapshots. Use for sequence review; verify mushy zone evolution and whether risers feed before complete pinch-off.
Sand Restraint Slider 0 = flexible/collapsible mold behavior, 1 = rigid constraint. Raise for rigid molds to reduce unrealistic deformation-assisted feeding in the model.
Model Opacity Controls base geometry transparency. Lower opacity when checking interior risk clouds.
Cross Section Clips the model for interior inspection along an axis and position. Use for validating hidden riser feeders, chill paths, and internal thick-light sections.

Result View Interpretation

View What values mean How to judge a good casting
Model Only No defect overlay, geometry-only check. Use to confirm orientation, riser/chill labeling, and regions of concern before defect views.
Shrinkage/Porosity Higher value = higher risk probability. The threshold shows voxels above that value. Good target: small, disconnected red/yellow clusters, preferably near non-critical regions and away from casting body.
Hot Spots Higher value = more likely hot spot trapping zone; dashboard count uses >0.3 threshold internally. Good target: no large clusters near junctions and thick cores.
Niyama Criterion Model maps computed severity from directional solidification. Lower Niyama number means higher risk, but map uses higher severity values for worse regions. Good target: high gradient, feed-open paths near risers/chills and no sustained high-severity boundary along thick sections.
Fraction Liquid Shows only voxels with fraction liquid above threshold; time slider moves from just poured to near full solid. Good target: coherent progression from feeders toward heavy sections, and feeder closure only after downstream sections are fed.

Quick Start by Casting Type

Part Type Start Settings Validation Order Action
Thin wall / fins Start with Auto Mesh ON, enable Fraction Liquid. Use 20-25% threshold on shrinkage as baseline. 1) Geometry + manual checks (orientation)
2) Shrinkage/Porosity + Fraction Liquid
3) Confirm no late mush trapped near risers/chills.
Thick bosses / heavy sections Set Refinement higher (3-4), use smaller Voxel Size. Enable Hot Spot + Shrinkage/Porosity. 1) Shrinkage/Porosity (30% then 15-20%)
2) Hot Spot overlap on top of shrinkage
3) Add/adjust riser/chill and re-run.
Complex junctions / internal pockets Enable Cross Section + lower Model Opacity. Keep Fraction Liquid open for timing. 1) Model + Hot Spot view
2) Fraction Liquid sweep (0→100%)
3) Confirm feeding path continuity before solid closure.
Foundry-risk alloy / difficult to cast alloys Start with CF8 / narrow threshold settings enabled. Use lower riser closure risk threshold (15-20% for review). 1) Enable Shrinkage + Niyama
2) Check overlap regions and local isolation
3) Use cross section to verify chill or feeder placement.

Workflow to Verify a Good Casting

  1. Enable Shrinkage/Porosity first to identify gross risk regions.
  2. Set threshold to 20-30%, then reduce toward 10-15% to inspect only severe zones.
  3. Enable Hot Spot and compare overlays. Confirm hotspots and shrink zones overlap in physically expected regions.
  4. Enable Niyama and compare with shrink view in the same geometry area.
  5. Check Fraction Liquid for timing:
    • Feeders should remain liquid long enough to keep feeding paths open.
    • High-risk zones should shrink/resolve as the solidification front reaches feeders/chills.
  6. Use cross-section and lower model opacity to inspect feeder and chill effectiveness through walls.
  7. Export screenshot once views are stable and risk clusters are acceptable.

The simulator is predictive, not a substitute for foundry process qualification. Use it as a design filter and compare against gate approvals and physical test data.
