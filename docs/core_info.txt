Core (PartType.CORE) — Thermal and Simulation Behavior
=======================================================

A sand core is a conducting sand volume in the voxel thermal field. It
absorbs heat from the metal at first, heats through ("saturates") when
metal encloses it, and then insulates the metal around it. That is what
makes a small core enclosed by thick metal a late hot spot, and the model
now reproduces it. The simulator is voxel-only; the tetrahedral path that
used to delete core tets was removed.

1. Core material (core/solidification_params.py, ThermalBoundaryParams)
   Sand properties are thermal-boundary parameters, not a core/materials.py
   entry (that file holds casting alloys only):
   - core_thermal_conductivity = 0.6 W/(m·K)
   - core_density              = 1600 kg/m³
   - core_specific_heat        = 1140 J/(kg·K)  (mean over 20-1500 °C)
     -> alpha = 3.3e-7 m²/s, the same sand as mold_thermal_diffusivity
   Constant properties; no latent heat. Temperature-dependent sand curves
   (quartz inversion at 573 °C, radiation above ~1000 °C, binder/moisture
   endotherms) are not modelled yet.

2. How a core enters the solve (core/solidification.py)
   - _initialize_thermal_models: core voxels get diffusivity and rho*cp
     overrides (concatenated with the chill overrides) and a metal-sand
     contact conductance.
   - _initial_thermal_temperatures: cores start at mold_temperature (21 °C)
     with or without a filling stage.
   - _preset_mold_solid_state: chills and cores start pre-solid (fs = 1,
     start/end/local times 0, feeding fs 1). fs_prev = 1 makes the latent
     heat correction a no-op, keeps cores out of the feeding trace, and lets
     the all-solid stop test pass.

3. Metal-core interface (physics/heat_transfer.py, contact_conductance)
   Every link with exactly one end in a core carries htc_core_contact
   (1000 W/(m²·K)) in series with the pair conductivity:
       k_ij -> k_ij / (1 + k_ij / (h * dx))
   so the interface conductance per area is 1 / (dx/k_ij + 1/h). It is
   constant: the casting shrinks onto a core rather than away from it, so
   there is no air-gap decay; the drop in heat flow comes from the sand
   heating up. Applied in all four conduction kernels (NumPy and Numba, plain
   and cut-cell).

4. Core prints (_configure_thermal_boundaries)
   Core voxels on the outer surface of the assembly (prints, seated in mold
   sand) get their own INTERFACE group: htc_core_print = 300 W/(m²·K) to
   mold_temperature, with the semi-infinite sand penetration decay and a low
   floor (core_print_htc_floor_fraction = 0.1). Enclosed cores need no
   boundary: they conduct as sand.

5. Downstream analyses
   - Shrinkage, porosity, hot spots, sand burn-in and the display masks
     exclude core voxels like chills (they are sand, never metal).
   - Niyama: the metal temperature gradient no longer samples core
     neighbours (low-k sand carries the steep delta-T on its own side), and
     the surface guard that zeroes risk on chill-backed metal does not apply
     to core-backed metal, where the late hot spot forms.
   - Gas porosity: cast voxels touching a core are gas sources labelled
     "core" (weight 1.0, phenolic-urethane binder, core venting 0.5) using
     the metal's local solidification time, so enclosed cores now generate
     gas. Before, only geometric-surface voxels (core prints) did.
   - Hot tear: core_restraint_index still defaults to 0.0 (no-op).

6. Effect (tests/test_core_thermal.py)
   2 in WCB cube with an enclosed 1 in core at 0.2 in voxels: the core heats
   from 21 °C to a mean of ~1160 °C; metal against the core freezes at
   ~93 s mean against ~48 s for the outer skin, and the last 5 % of metal
   to freeze all touches the core.

7. Known limits / follow-ups
   - The outer-mold air-gap floor (0.35 -> constant 175 W/m²K after ~5 s)
     still keeps the outer mold from saturating; it may be calibrated and is
     a separate investigation.
   - Surrogate and deep models were trained on the old core behaviour and
     need retraining.
